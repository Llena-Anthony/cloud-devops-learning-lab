This repository documents focused exercises and the reasoning behind them. Entries emphasize reproducible commands, security-aware notes, and lessons learned rather than unredacted infrastructure details or fabricated results.

## Security Notes

The repository excludes credentials, private keys, environment files, Terraform state, and personally identifying network details. Lab notes intentionally omit public IP addresses, instance IDs, and copied terminal output that could contain sensitive data.
